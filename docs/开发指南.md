# 山河序 · 开发指南（接手必读）

「赓续血脉・数绘红旅」：**原生 HTML / CSS / JS + ES Modules**，无框架、无打包、纯静态，GitHub Pages 部署。7 个页面，39 个 ES 模块，统一入口 `js/app.js`。本站在"无框架"前提下用了一套自创约定（`data-action` 委托、`?v=` 缓存破击、CSS 令牌等）——**遵守约定 = 一次改对；违反约定 = 部署后"改了不生效"或上线 404**。读完全文约 10 分钟。

---

## 一、5 个命令

| 命令 | 作用 | 什么时候用 |
|---|---|---|
| `npm start` | 本地静态服务 `localhost:9876`（PORT 可覆盖） | 日常预览。**必须 HTTP**，`file://` 下 ES Module/fetch 全挂 |
| `npm test` | 40 项零依赖契约测试（node --test） | 改数据/样式/逻辑后 |
| `npm run smoke` | Playwright + 系统 Chrome 无头开 7 页，抓 JS 异常/模块 404/资源 404 | 改运行逻辑后（需 `npm ci` + 本机 Chrome） |
| `npm run audit` | 提交前体检：版本一致 / import 完整 / 死引用 / 资源存在 / 约定检查 | **每次提交前（硬性）** |
| `npm run bump` | 把 `js/version.js` 的版本号同步到全站 `?v=` 与 js/ 相对 import | **改任何 js/css/html 后（硬性）** |

**提交铁律：`npm run audit` + `npm test` 必须全绿；改 js/css/html 必须 `npm run bump`。**

## 三、10 条约定（违反 = audit/test 红，或部署翻车）

1. **版本号**：唯一源 `js/version.js`（`ASSET_VERSION`，10-16 位纯数字）。改任何 js/css/html → `npm run bump`。**不 bump = 浏览器强缓存旧模块，"改了不生效"。**
2. **路径三件套**：`getBasePath()`（子页返回 `../`）、`resolveAssetPath()`（图片）、模板 `{{BASE}}`。**禁硬编码 `./` 或裸相对路径**（audit 3.6 会拦裸 fetch/href）。
3. **交互**：全站用 `[data-action="值"]` + `js/action-delegate.js` 单一 switch。新增交互 = 元素加 data-action + 在 switch 加 case。**禁内联 `onclick`**（audit 3.6 会拦）。
4. **模块**：新模块只能 import 叶子/上游，禁 import app.js；**建议**小写连字符命名（bump/audit 正则自 2026-08-13 已支持 `./`、`../` 与大小写混合名，但全站保持小写连字符一致）；文件头注释块（职责/约束/依赖）；一文件一导出 `initX()`。
5. **数据**：JSON 统一走 `data.js` 的 `loadJSON`（带 basePath/缓存/?v=）。**禁裸 `fetch('data/...')`**（audit 3.6 会拦）。
6. **CSS 令牌**：颜色/圆角/时长/间距用 `:root` 令牌，禁裸 hex/魔法值。间距 4px 网格、圆角只取 `--radius-*` 刻度、≤0.6s 时长走令牌、font-size ≥12px。`npm run converge` 可自动收敛。
7. **深色模式**：`html.dark` 类（documentElement）+ localStorage `redguide_dark`。新增令牌 = base.css `:root` + dark.css `html.dark` 双份。dark.css 必须每页最后加载。红底文字用 `--on-primary`，禁 `--white`。
8. **存储**：用 `safeStorage`；key 白名单 `redguide_favs/dark/likes_<id>/messages/quiz/chat/bgmusic_*`，别发明新 key。
9. **安全**：所有动态文本 `escapeHtml` + URL `sanitizeUrl`；禁把未转义字符串拼进 innerHTML（留言 sessionStorage 回填是 XSS 面）。
10. **emoji**：交付物（HTML/JS）禁 emoji，用 `js/icons.js` 的 `icon()`（★✕✦☰ 排版符号除外）。

## 四、常见任务操作清单

### 加一个场馆
1. 核心场馆 → `data/venues.json`（数字 id + 完整坐标，lat 15-55 / lng 70-140，名字唯一）
2. 扩展场馆 → `data/province-candidates.json`（标准名不能撞核心/别名，否则静默丢弃）+ `data/extended-venues-meta.json`（`assets/` 开头的 image + category + 坐标）
3. 详情文字 → `data/venue-details.json`（键名 = 场馆显示名）
4. 图片 → `assets/全国红色场馆图片/`
5. 跑 `npm test`（data.test.js 校验形状）

### 加一个 data-action
1. 元素加 `data-action="my-action"` + 所需 `data-*`
2. `js/action-delegate.js` 的 switch 加 `case 'my-action':`
3. 逻辑实现放进所属模块（页面私有动作放 pages.js）
4. 跑 `npm test`（data-action 闭环测试强制）

### 加一个 JS 模块
1. `js/` 下新建，**小写连字符**命名，头注释块（职责/约束/依赖）
2. 只 import 叶子/上游，import 带 `?v=`（用当前 ASSET_VERSION）
3. 导出 `initX()`
4. 在 `js/app.js` boot 里接入（或经 pages/action-delegate 调用）
5. `npm run bump` + `npm run audit` + `npm test` + `npm run smoke`

**模块骨架（复制改名即用）**：

```js
/* ============================================================
   xxx — 职责一句话（高内聚：一个模块只干一件事）
   约束：只依赖 utils/version/icons 等叶子或上游；被 xxx 引用
   ============================================================ */
import { getBasePath } from './utils.js?v=2026081302'; // 用当前 ASSET_VERSION（js/version.js）

let state = null; // 模块级状态，模块内自包含，不泄漏

function initX() {
  // 幂等：已初始化则跳过，避免重复绑定
  if (state) return;
  state = true;
  // …初始化逻辑…
}

export { initX };
```

### 加一个页面
1. `pages/xxx.html`，head 引 7 个 css（base→home→components→pages→widgets→effects→dark）+ `../js/app.js?v=`
2. 含 `<div id="site-header">`、`<div id="site-footer">`、`<template id="footer-extra">`
3. `js/pages.js` 的 autoInit 加路由分支 + 新建控制器
4. 加到 `tests/e2e/smoke.test.js` 的 pages 数组
5. 有顶部 hero 想轮播：单图改双图（`hero-bg-active` + `hero-bg-next`）+ section 加 `data-hero-images`（JSON 数组）

### 加图片/素材
- 放 `assets/` 对应中文目录（`assets/页面通用图片/`、`assets/全国红色场馆图片/`、`assets/通用/` 等），**目录名必须字节级保留**
- 引用走 `resolveAssetPath`；图片加 `data-fallback`（禁内联 onerror）
- 素材来源/授权补进 `docs/素材说明/`

## 五、测试就是规矩

测试不是装饰，是约定和数据结构约束的具象化：

| 测试 | 守什么 |
|---|---|
| `data-action.test.js` | 每个 data-action 值都有 case（交互闭环） |
| `data.test.js` | 数据形状硬约束（30 题、300 热力、15 场馆、34+1 地图、meta 键闭环） |
| `design-tokens.test.js` | CSS 令牌刻度（间距 4px、圆角刻度、时长令牌） |
| `colors-converged.test.js` | 语义色收敛、深色双份 |
| `a11y-html.test.js` | 无障碍（footer aria-label、back-to-top 可见态等） |
| `audit.js` | 版本/import/死引用/资源/约定检查（提交前） |

**改数据/样式前，先读对应测试——它们会告诉你"能怎么改"。**
