# 赓续血脉・数绘红旅 — 全国红色文旅数字导览平台 项目说明

> **活动**：四川农业大学信息工程学院「青践红途・码绘山河」系列活动
> **团队**：忘川山河序
> **线上地址**：https://yinxi666.github.io/shanhexu/
> **技术栈**：原生 HTML / CSS / JavaScript(ES Modules,无框架、无后端、无数据库)

---

## 一、项目简介

本项目以"赓续血脉、数绘红旅"为主题,依托 Web 技术搭建**全国红色文旅数字导览平台**。平台汇聚全国 **32 个红色场馆**的图文数据,提供沉浸式智能导览、知识问答、长征互动、热力图分析、社会实践成果展示等功能,同时以数字技术拓宽红色资源传播渠道,展现青年学子"以技术传红"的实践初心。

## 二、设计理念

1. **红色为本,数字赋能**:以红色场馆与革命历史为核心内容,用前端交互技术增强感染力。
2. **沉浸式叙事**:以"重走长征路"为线索,通过物理手卷滚动、站台印章、诗词浮现、气候粒子等营造沉浸式红色记忆体验。
3. **真实可溯源**:数据尽量采用官方来源(如热力图数据取自国家发改委《全国红色旅游经典景区名录》),图片标注授权来源。
4. **纯静态、零依赖**:严格遵循竞赛"不设置后端、数据库及管理员端"要求,全部功能由浏览器端完成。

## 四、技术实现

- **架构**:原生 ES Modules,单一入口 `js/app.js`,39 个模块按职责拆分、依赖单向无环。共享页头/页脚由运行时模板注入。
- **设计系统**:8 个 CSS 文件 + 设计令牌(`:root` 变量)统一颜色/圆角/间距/动效,深色模式通过令牌覆盖实现。
- **数据层**:`data/*.json` 集中管理场馆/详情/政策/实践/留言数据;热力图分省数据取自官方名录。
- **地图**:Leaflet(高德瓦片)+ 自定义红色五角星 Marker;场馆详情页跳转高德地图导航。
- **可视化**:Apache ECharts 中国地图热力图(加载失败自动降级 SVG)。
- **交互**:`data-action` 事件委托替代内联 onclick;焦点圈定、键盘可达等无障碍支持。
- **性能**:资源按需加载(`preload="none"`),图片懒加载,版本号缓存破击。
- **工程**:`scripts/audit.js` 静态审计、契约测试(40 项)、Playwright 运行时冒烟测试(7 页加载 + 17 项交互行为测试)、GitHub Actions 自动测试+部署。

## 五、创新点

1. **重走长征手卷**(核心创新):以纵向滚动驱动横向物理手卷展开 17 站长征路线,站台印章、笺纸卡片、诗词浮现、气候粒子小剧场,到达延安触发终点成就纪念卡。
2. **红色纪念卡**:Canvas 实时合成可下载/分享的红色文创纪念卡(背景图+姓名+精神词)。
3. **全国红色旅游经典景区分布热力图**:基于《全国红色旅游经典景区名录》官方分省数据,ECharts 完整地图与内联 SVG 降级两条渲染路径统一。
4. **知识挑战赛**:30 题题库每局随机抽 10 题,上一题/下一题导航、即时反馈。
5. **深浅色双模式**、全站 SVG 图标体系、双层帷幕页面过渡。

## 七、部署与本地运行

- **线上**:GitHub Pages 静态托管,推送 `main` 分支自动构建部署(先跑审计与测试)。
- **本地**:纯静态,任意静态服务器即可运行(如 `python -m http.server 3000` 或 `node server.js`,端口 9876)。注意需通过 HTTP 访问(ES Modules 与 fetch 不支持 `file://`)。

## 八、演示建议(3-5 分钟)

1. **开场**(30 秒):首页电影级入场动画 → 全国红色旅游经典景区分布热力图。
2. **导览**(1 分钟):全国导览页搜索/筛选 → 点击场馆进详情 → 高德地图导航。
3. **长征沉浸**(1 分钟):重走长征手卷滚动展开,展示印章/诗词/终点纪念卡。
4. **智能交互**(1 分钟):AI 助手问答(如"红船精神是什么""推荐一条红色路线")→ 知识挑战赛答题。
5. **收尾**(30 秒):留言墙提交、深色模式切换、实践成果视频,展示移动端适配。
