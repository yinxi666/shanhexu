# 静态网页部署说明

本项目已改为纯静态网页，不需要 Node.js、数据库、后端接口或运行时写入目录。学校服务器只要能托管 HTML、CSS、JS、JSON、图片和视频文件即可。

## 一、上传目录

将整个 `红色文旅数字导览平台基础代码包` 文件夹上传到静态网站目录，例如：

```text
/var/www/shuhui-hongtu
```

也可以上传到学校提供的静态网页空间、Nginx、Apache、对象存储静态网站、GitHub Pages、Netlify、Vercel 静态项目等环境。

## 二、访问入口

部署后访问：

```text
https://你的域名/index.html
```

如果服务器配置了默认首页，也可以直接访问域名根路径。

## 三、静态资源要求

请确保服务器允许访问以下类型文件：

- `.html`
- `.css`
- `.js`
- `.json`
- `.jpg`、`.jpeg`、`.png`、`.webp`
- `.mp4`

如果页面能打开但场馆、政策或实践列表为空，通常是服务器禁止访问 `.json` 文件，需要在静态服务器配置中允许 JSON 静态资源。

## 四、本地预览

由于浏览器可能限制 `file://` 页面读取 JSON，建议在项目目录运行一个静态服务：

```bash
python -m http.server 3000
```

然后访问：

```text
http://localhost:3000
```

## 五、后续扩展

如果参赛队需要登录、留言持久化、后台管理、图片上传、审核、统计等功能，可以在静态基础包之外自行接入后端、数据库或学校提供的接口平台。
