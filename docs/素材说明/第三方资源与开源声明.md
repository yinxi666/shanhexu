# 第三方资源与开源声明

> 本项目为**纯静态网页**,运行时不依赖任何后端服务。本文件列明页面运行时使用的第三方开源库、CDN 资源、地图瓦片服务、字体与音频素材的来源与许可。**场馆图片与实践图片的授权说明见《素材来源与授权说明.md》。**

## 一、开源前端库(CDN 引入)

| 库 | 版本 | 用途 | 许可 | 引入方式 |
|---|---|---|---|---|
| **Apache ECharts** | echarts@5 | 首页全国红色旅游经典景区分布热力图 | Apache License 2.0 | `<script src="https://cdn.jsdelivr.net/npm/echarts@5/dist/echarts.min.js">` |
| **Leaflet** | leaflet@1.9.4 | 全国导览页交互式地图 | BSD-2-Clause | 自托管 `assets/leaflet/leaflet.js` + `leaflet.css`（2026-08-13 起，原 unpkg CDN 因国内可达性不稳定改为本地同源加载，随站点打包） |

- ECharts: https://echarts.apache.org/ (Apache License 2.0)
- Leaflet: https://leafletjs.com/ (BSD 2-Clause)

## 二、地图瓦片服务

| 服务 | 说明 | 用途 |
|---|---|---|
| **高德地图(Amap)瓦片** | `https://webrd0{s}.is.autonavi.com/appmaptile?...` | 全国导览页 Leaflet 底图 |
| **高德地图 URI API** | `https://uri.amap.com/marker?...` | 场馆详情页"在高德地图中查看"跳转 |

均来自高德开放平台的地图服务,本项目仅用于教育性质的竞赛演示,遵循高德开放平台服务条款(非商用场景)。
