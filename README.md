# 赓续血脉・数绘红旅 — 红色文旅数字导览平台

> "青践红途・码绘山河"系列活动 · 四川农业大学信息工程学院 · **忘川山河序**

🌐 **在线访问**：https://yinxi666.github.io/shanhexu/

---

## 项目简介

以数字技术传承红色基因、用实践行动践行青年使命。本平台汇聚全国 **32 个红色场馆**的图文数据，提供智能导览、知识问答、热力图分析、实践成果展示等功能，打造沉浸式红色文化学习体验。

## 技术栈

| 类型 | 技术 |
|------|------|
| 前端 | 原生 HTML / CSS / JavaScript（无框架） |
| 地图 | ECharts（热力图）+ Leaflet（场馆分布） |
| 图标 | 高德地图（坐标导航）+ 自定义红色五角星 Marker |
| 字体 | 弘雷卓书（CDN）+ 系统字体 |
| 动效 | Canvas 入场动画 + 双层帷幕切换 + View Transitions API |
| 音频 | Web Audio API（背景音乐播放器） |
| 部署 | GitHub Pages 静态托管 |

## 功能模块

| 模块 | 说明 |
|------|------|
| 🏠 **首页** | Canvas 电影级入场动画（天安门剪影/火焰蔓延/雁阵/五角星）、背景诗词浮层、数据统计、ECharts 热力图、红色记忆时间线 |
| 📍 **全国导览** | 左右分栏（列表 + 常驻地图）、搜索胶囊工具栏、卡片hover联动地图marker高亮、Leaflet 自定义五角星标记、高德瓦片、3×3 卡片网格 |
| 🚩 **重走长征** | 物理手卷滚动展开 17 站长征路线、站台印章/笺纸卡片/诗词、气候粒子小剧场、终点成就纪念卡 |
| 🎴 **红色纪念卡** | Canvas 合成红色文创纪念卡（背景图+姓名+精神词），支持下载/分享，可与场馆联动 |
| 🏛️ **场馆详情** | 图片轮播、操作按钮栏（返回/分享/打印）、历史背景、教育意义、高德地图坐标导航、官网链接 |
| 📰 **时事政策** | 时间轴竖线布局、日期胶囊标签、卡片连接线、10 条政策文章（按时间排序）、分页 |
| 🏆 **实践成果** | 3×2 卡片网格、视频常驻播放按钮+脉动角标、迷你日历牌日期、团队标签、点赞胶囊按钮、左侧红条hover动效 |
| 💬 **留言墙** | 软木板纹理背景+木框、2×2 卡片网格、彩色头像（名字hash）、随机倾斜、彩色图钉、表单提交印章动画 |
| 🤖 **AI 助手** | 智能问答（30+ 知识库）、场馆搜索、路线推荐、统计查询、历史时间线、悬浮聊天面板 |
| 🧠 **知识问答** | 12 道红色知识挑战赛、即时反馈、得分统计 |
| 🌓 **深色模式** | 一键切换，localStorage 持久化 |
| 🎵 **背景音乐** | 浮动播放器（播放/暂停+音量滑条）、跨页面续播、浏览器自动播放拦截后等待交互恢复 |
| 🎬 **页面切换** | 自研双层帷幕（红纱+五星纹理）从右滑入 + 浏览器 View Transitions |

## 本地运行

纯静态网页，无需安装依赖。直接双击 `index.html`，或使用任意静态服务器：

```bash
# Python
python -m http.server 3000

# Node.js
node server.js
```

## 创新功能

- 🎬 **Canvas 电影级入场动画**：6.4 秒叙事时间线（星火→黎明→山脉→天安门→标题），底部红色诗词渐次浮现，移动端性能自适应
- 🤖 **AI 智能导览助手**：基于规则引擎的对话式问答，30+ 知识库覆盖历史事件/红色精神/场馆搜索/路线推荐
- 🗺️ **分栏导览地图**：左侧卡片列表 + 右侧常驻地图，卡片 hover 联动 marker 金色高亮呼吸动画
- ⛰️ **淡墨山水底纹 + 宣纸纹理**：CSS 纯渐变模拟水墨远山和手工宣纸质感
- 🧭 **政策时间轴**：网格布局竖线+圆点+日期胶囊+连接线，按时间排序
- 🃏 **软木板留言墙**：2×2 网格 + 随机倾斜 + 彩色头像 + 图钉 + 提交印章动画
- 🎵 **背景音乐播放器**：浮动胶囊按钮+横向音量滑条，跨页面续播进度记忆
- 🚩 **重走长征手卷**：纵向滚动驱动横向物理手卷展开，17 站站台印章/笺纸卡片/诗词浮现，气候粒子小剧场，到达延安触发终点成就
- 🎴 **红色纪念卡**：Canvas 合成可下载/分享的红色文创纪念卡，支持场馆图背景与自定义寄语
- 🎭 **双层帷幕切换**：点击导航红纱从右滑入，五星SVG纹理+金色竖线，0.55 秒过渡
- 📱 **移动端适配**：响应式断点 + 浮动按钮竖排 + 底部导航栏 + 入场动画降级
