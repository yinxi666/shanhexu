# “赓续血脉・数绘红旅”红色文旅数字导览网页设计竞赛基础模板

这是“青践红途・码绘山河”系列活动中“赓续血脉・数绘红旅”红色文旅数字导览网页设计竞赛的起步模板。模板只提供首页、四个主题页面、统一导航、基础样式和素材目录，不提供现成业务功能。

## 文件结构

- `index.html`：首页与页面入口。
- `pages/guide.html`：红色场馆导览待设计页面。
- `pages/message.html`：学习留言墙待设计页面。
- `pages/policy.html`：时事政策待设计页面。
- `pages/practice.html`：实践成果待设计页面。
- `css/styles.css`：导航、首页和空白内容区的基础样式。
- `js/common.js`：只处理移动端导航和当前页面标记。
- `assets/`：图片、视频和页面通用素材。
- `data/`：供参赛者选用的原始示例数据，页面不会自动读取或展示。
- `docs/素材说明/`：素材来源、隐私与上线核验说明。

## 运行方式

本项目是纯静态网页。解压后可直接双击 `index.html` 浏览，也可以部署到任意静态网站空间。

建议使用任意静态 Web 服务预览，例如：

```bash
python -m http.server 3000
```

启动后访问 `http://localhost:3000`。

## 参赛者需要完成

1. 自主设计四个主题页面的内容和视觉形式。
2. 自主选择、整理和核验展示数据。
3. 自主实现搜索、筛选、地图、留言、互动等功能。
4. 自主完成作品的特色设计和技术创新。

## 注意事项

- 正式参赛作品应注明第三方素材、开源代码、接口和模型来源。
- 公开展示学生信息前必须做好隐私保护。
- 场馆开放时间、预约方式、位置和票务等信息正式上线前需再次核验。
- 本模板只作为页面起点，不替代参赛者自己的功能实现与界面设计。
