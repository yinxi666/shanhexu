# 赓续血脉・数绘红旅 — 红色文旅数字导览平台

> "青践红途・码绘山河"系列活动 · 四川农业大学信息工程学院 · **忘川山河序**

🌐 **在线访问**：https://yinxi666.github.io/shanhexu/

---

## 项目简介

以数字技术传承红色基因、用实践行动践行青年使命。本平台汇聚全国 **32 个红色场馆**的图文数据，提供智能导览、知识问答、热力图分析、实践成果展示等功能，打造沉浸式红色文化学习体验。

## 技术栈

| 类型 | 技术 |
|------|------|
| 前端 | 原生 HTML / CSS / JavaScript（无框架） |
| 地图 | ECharts（热力图）+ Leaflet（场馆分布） |
| 图标 | 高德地图（坐标导航） |
| 字体 | 系统字体（微软雅黑 / 宋体） |
| 部署 | GitHub Pages 静态托管 |

## 功能模块

| 模块 | 说明 |
|------|------|
| 🏠 **首页** | Cinematic Hero 动画、数据统计、ECharts 中国热力图、精选场馆、最近浏览 |
| 📍 **全国导览** | 搜索筛选（地区/类别/关键词）、卡片列表、Leaflet 交互地图、分页 |
| 🏛️ **场馆详情** | 图片轮播、历史背景、教育意义、高德地图坐标导航、官网链接 |
| 📰 **时事政策** | 10 条政策文章、直达原文链接 |
| 🏆 **实践成果** | 20 项实践成果、视频播放、画廊图片、点赞、详情弹窗、分页 |
| 💬 **留言墙** | 15 条预设留言、前端模拟表单提交 |
| 🤖 **AI 助手** | 智能问答（30+ 知识库）、场馆搜索、路线推荐、统计查询、历史时间线 |
| 🧠 **知识问答** | 12 道红色知识挑战赛 |
| 🌓 **深色模式** | 一键切换，localStorage 持久化 |

## 本地运行

纯静态网页，无需安装依赖。直接双击 `index.html`，或使用任意静态服务器：

```bash
# Python
python -m http.server 3000

# Node.js
node server.js
```

## 创新功能

- 🤖 **AI 智能导览助手**：基于知识库的对话式问答，支持场馆搜索、路线推荐、历史事件查询、省份排名等
- 🗺️ **ECharts 中国热力图**：可拖拽/缩放，支持 +/− 按钮控制
- 📍 **Leaflet 交互地图**：导览页列表/地图双视图切换，高德瓦片
- 🌓 **深色/浅色模式**：完整双主题 CSS 变量体系
- 📱 **移动端适配**：8 个响应式断点 + 底部导航栏 + 浮动按钮优化
- 📄 **实践成果详情弹窗**：画廊灯箱 + 视频播放
